# UI Style: "Paper Ledger" (สมุดบัญชี + ตราประทับ)

เอกสารนี้คือภาษาการออกแบบของ UI ทั้งระบบ ใช้เป็นมาตรฐานเมื่อสร้างหน้าหรือคอมโพเนนต์ใหม่ และใช้เป็น prompt ตั้งต้น (base UI) ให้ AI หรือโปรเจกต์อื่นได้
ค่าจริงอยู่ใน `src/app/globals.css` (tokens, scrollbar, stamp animation), `src/components/layout/AppShell.tsx` (sidebar + header), `src/components/shared/Stamp.tsx` (ตราประทับ)

หน้าตาทุกหน้า ทุกคอมโพเนนต์ ทุกสถานะ (hover, focus, disabled, empty, loading, error) ต้องอยู่ใน style เดียวกัน ห้ามใช้หน้าตา default ของ shadcn/Tailwind ที่ไม่ผ่านการปรับตามนี้

## 1. แนวคิดหลัก

ระบบทำงานเสมือน "เอกสารราชการบนโต๊ะทำงาน":

- **แผ่นกระดาษครีม** (การ์ด, ตาราง, ฟอร์ม) วางอยู่บน **โต๊ะ** ที่เข้มกว่าเล็กน้อย
- **หมึกสีน้ำตาลอุ่น** แทนสีดำล้วน
- **แดงหมึกตราประทับ** เป็นสีเน้นเดียว ใช้เฉพาะ: ปุ่มหลัก, สถานะสำคัญ, ตราประทับ, ตัวบอกตำแหน่งปัจจุบัน
- ผลลัพธ์ของการกระทำสำคัญ (อนุมัติ/ปฏิเสธ/สำเร็จ) ต้องปรากฏเป็น **ตราประทับ** บนเอกสาร ไม่ใช่ badge สีสดทั่วไป
- อารมณ์: เป็นทางการ นิ่ง อุ่น ไว้ใจได้ ไม่ใช่ SaaS มันวาว ไม่ใช่ glassmorphism ไม่ใช่ gradient

**หลัก "เบา ไม่เวอร์":** ให้ลายเซ็นของสไตล์อยู่ในไม่กี่จุด (แท็บ, ตราประทับ, เส้นประ, เส้นคู่) ห้ามใส่ลูกเล่นทุกที่
เคยลองรูเจาะสมุด, เลขกำกับ, การเอียงหลายจุดแล้วดู "เวอร์" — อย่าใส่

## 2. Design tokens (CSS variables, HSL แบบ shadcn `H S% L%`)

Light (`:root`):

```
--background: 38 28% 92%      /* โต๊ะ */
--foreground: 28 22% 14%      /* หมึก */
--card: 42 60% 97%            /* กระดาษ */
--popover: 42 60% 98%
--primary: 356 70% 47%        /* แดงหมึก (สีแบรนด์ — สลับได้) */
--primary-foreground: 0 0% 100%
--secondary / --muted / --accent: 38 25% 90%
--muted-foreground: 30 12% 38%
--destructive: 356 65% 50%
--success: 142 60% 28%
--warning: 32 90% 34%
--border: 36 22% 78%
--input: 36 22% 74%
--ring: 356 70% 47%
--radius: 0.25rem              /* มุมเหลี่ยม ห้ามมนเกิน 4px */
--sidebar: 28 18% 13%          /* หมึกเข้ม */
--sidebar-foreground: 40 40% 94%
--sidebar-accent: 356 70% 47%
```

Dark (`.dark`, ปรับให้อบอุ่น ไม่ใช่เทาเย็น): background `28 12% 8%`, card `28 12% 12%`, foreground `40 30% 92%`, border `28 8% 20%`, primary `356 70% 54%`, sidebar `28 14% 6%`, success `142 55% 45%`, warning `38 85% 55%`

กฎ:

- ใช้ token เสมอ ห้าม hard-code สี (ยกเว้นสีพื้นโต๊ะของหน้า login)
- ทุกสีต้องสลับ dark mode ได้เอง
- เปลี่ยนแบรนด์ให้เปลี่ยนเฉพาะ `--primary`, `--ring`, `--sidebar-accent` (hue 356 → hue ของแบรนด์)

## 3. ตัวอักษร

- Sans: Geist (+ ฟอนต์ไทยที่อ่านง่ายเป็น fallback) ข้อความ UI ทั้งหมดเป็นภาษาไทยเท่านั้น
- Mono: Geist Mono สำหรับ **ตัวเลข/รหัสที่เป็นข้อมูลเอกสาร**: เลขที่เอกสาร (`FORM-0042`), วันที่ในตาราง, ทะเบียน, username, ป้ายเล็ก
- น้ำหนัก: ใช้ `font-medium` เป็นหลัก หลีกเลี่ยง bold; หัวข้อหน้า `text-lg font-medium`
- label ฟิลด์: `text-xs text-muted-foreground`; ข้อความค่า: `font-medium`
- ป้ายเล็ก uppercase/mono: `text-[10px] tracking-[0.2em]`

## 4. รูปทรงและเส้น (ส่วนที่ทำให้ดูมีเอกลักษณ์)

- **มุม:** `rounded-[3px]` (หรือ `rounded-lg` ที่ map กับ `--radius`) ห้าม `rounded-xl/2xl/full` กับการ์ด/ปุ่ม/input
- **เส้นประ** (`border-dashed border-foreground/25`): คั่นภายในเอกสาร — ระหว่างแถวตาราง, ระหว่างเมนู, ใต้หัวข้อ, ใต้ฟิลด์ในใบเอกสาร
- **เส้นทึบบาง** (`border-foreground/30`): ขอบนอกของแผ่นกระดาษ
- **เส้นคู่** (`border-b-[3px] border-double border-foreground/30`): ใต้หัวเอกสาร/หัวหน้า
- **เงา:** เงาแข็งเยื้องแบบกระดาษวางบนโต๊ะ `shadow-[3px_3px_0_0_hsl(var(--foreground)/0.08)]` (แผ่นเดี่ยว เช่น login ใช้ 5px / 0.16) ห้ามเงาฟุ้งนุ่ม
- ห้าม gradient, ห้าม blur/glass, ห้ามเงาสี

## 5. คอมโพเนนต์

**Card / แผ่นกระดาษ:** `bg-card border border-foreground/30 rounded-[3px]` + เงาแข็งบาง หัวข้อคั่นด้วยเส้นประ

**Button:** primary = พื้น `--primary` ตัวอักษรขาว มุมเหลี่ยม; outline = เส้นบางสีหมึก; ghost สำหรับไอคอน; destructive ใช้เมื่อยืนยันการลบเท่านั้น

**Input / Select / Textarea:** สูง 36px, `border-input`, พื้นโปร่ง/การ์ด, focus = ring สี `--ring` 2–3px (ต้องเห็นชัด)

**Table:** ไม่มีพื้นสลับแถว; หัวตาราง `text-xs text-muted-foreground` + เส้นประใต้หัว; แถวคั่นด้วย `divide-dashed`; hover `bg-muted/50`; คอลัมน์รหัส/วันที่ใช้ mono; แถวที่ปิดใช้งาน `opacity-60`

**ตราประทับ (Stamp) — องค์ประกอบเอกลักษณ์:** กรอบ `border-[1.5px]` (เล็ก ในตาราง) หรือ `border-[3px]` (ใหญ่ บนเอกสาร) ตัวอักษร tracking-wide, มุม 3px

- อนุมัติ = แดง `--primary`; ปฏิเสธ = หมึกเข้ม `--foreground`; ยกเลิก = muted; รออนุมัติ = เส้นประ muted (ยังไม่มีตรา)
- เอียงเล็กน้อย (-2° เล็ก / -9° ใหญ่) เฉพาะเมื่อ "ตัดสินแล้ว"
- ตราใหญ่มีแอนิเมชัน "ประทับลง" (`.stamp-in`): เริ่ม scale 1.9 + blur 3px → กดลง 0.93 → เด้ง 1.04 → นิ่ง 1 ใช้เวลา ~0.55s, `cubic-bezier(.2,.8,.3,1)` ปิดเมื่อ `prefers-reduced-motion`
- ในตารางใช้ตราเล็กเรียบๆ อย่าให้ตราแน่นทั้งหน้า

**Sidebar:** พื้น `--sidebar` เข้ม มีแถบแดงหนา 3px ด้านบน; โลโก้เป็นกรอบแดงเหลี่ยม + ตัวอักษร mono; เมนูคั่นด้วยเส้นประจางๆ; เมนูที่เลือก = **แท็บสีกระดาษ** (พื้น `--background`, ตัวอักษร `--foreground`, ไอคอนแดง) ที่ยื่นไปชนขอบขวาเพื่อต่อกับพื้นที่เนื้อหา

**Header (แถบหัวหน้า):** เส้นคู่ด้านล่าง; ชื่อหน้าเป็น **แท็บสีกระดาษ** วางทับเส้นคู่ (พื้น `--card`, ขอบบนแดง 3px, มุมบนเหลี่ยม, เงาแข็งบาง) ปุ่มธีม/ผู้ใช้อยู่ขวา

**Toast (sonner):** แผ่นกระดาษ (พื้น `--card`, ขอบบาง, เงาแข็ง) + แถบสีซ้าย 4px ตามประเภท (success=เขียว, error=แดง, warning=อำพัน, info=แดงหลัก) ห้ามพื้นเต็มสี — ไม่ใส่ `richColors` ใน `<Toaster>`

**Dialog / Popover / Dropdown:** พื้นกระดาษ, มุมเหลี่ยม, เส้นประคั่นส่วน; ต้องมี max-height และเลื่อนในตัวเอง (`max-h-[calc(100dvh-2rem)] overflow-y-auto`)

**Select / Combobox ที่รายการยาว:** ต้องจำกัดความสูง (`max-h-[min(20rem,var(--radix-select-content-available-height))]`) และเลื่อนได้เสมอ; combobox ต้องครอบรายการด้วย `CommandList`

**Pagination:** เป็น `<button>` จริง (กด Tab ได้); หน้าปัจจุบัน = บล็อกแดงเต็ม; ข้อความ "ก่อนหน้า/ถัดไป"; แสดงตัวเลือกจำนวนต่อหน้าเสมอแม้มีหน้าเดียว (มิฉะนั้นเลือกกลับไม่ได้)

**Scrollbar:** ราง = เส้นประบางตรงกลาง; ก้าน = บล็อกแดงเหลี่ยม 12px มีขอบสีพื้นล้อม + ขีดจับ 3 ขีดสีขาวโปร่ง; hover เข้มขึ้น ใช้ `::-webkit-scrollbar` — ห้ามตั้ง `scrollbar-color` ตรงๆ เพราะ Chrome จะข้ามสไตล์แบบกำหนดเอง; ใส่ `@supports not selector(::-webkit-scrollbar)` เป็น fallback ของ Firefox

**หน้า Login:** แผ่นกระดาษเดียววางบนพื้นโต๊ะสีครีมเข้ม (`hsl(36 22% 82%)`, dark: `hsl(28 10% 9%)`) แถบแดง 3px บนสุดของหน้า; หัวแผ่น = ตราโลโก้ + "ใบเข้าใช้ระบบ" คั่นเส้นคู่; ท้ายแผ่น = เส้นประ + ข้อความช่วยเหลือ; error = แถบแดงซ้าย

**หน้าเอกสาร/รายละเอียด (permit slip):** เลขที่เอกสารแบบ mono มุมบน, ฟิลด์แต่ละช่องมีเส้นประใต้, ช่องลายเซ็นเป็นเส้นทึบ, ตราประทับใหญ่วางทับมุมล่างขวา, เมนู/ปุ่มต้อง `print:hidden` เพื่อให้พิมพ์ได้เอกสารสะอาด

**Empty / Loading:** empty = ข้อความสั้นนิ่งบนกระดาษเปล่ามีเส้นบรรทัดจางๆ; loading = skeleton สี `--muted` มุมเหลี่ยม ห้ามสปินเนอร์สีสด

## 6. Motion

มีแค่: ตราประทับลง, transition สี/เงาสั้น (150–200ms), dialog/popover fade-zoom ห้ามแอนิเมชันตกแต่งอื่น เคารพ `prefers-reduced-motion`

## 7. Responsive

- Sidebar: `md` ขึ้นไปเป็นคอลัมน์คงที่ (~228px), ต่ำกว่า `md` เป็น drawer เลื่อนจากซ้าย + overlay ดำ 50%, ปิดด้วย Esc / คลิกนอก / เปลี่ยนหน้า, ล็อกสกอลล์หลังตอนเปิด
- ตารางกว้างต้องอยู่ใน `overflow-x-auto` พร้อม `min-w-*`
- gutter ด้านข้าง 16px บนมือถือ, 24px บนเดสก์ท็อป; ห้ามเกิดสกอลล์แนวนอนของทั้งหน้า
- touch target อย่างน้อย 36–40px

## 8. Accessibility

คอนทราสต์ตัวอักษรอย่างน้อย WCAG AA ทั้ง light/dark, focus ring เห็นชัดทุกคอมโพเนนต์, ทุกปุ่มไอคอนมี `aria-label`, ห้ามสื่อสถานะด้วยสีอย่างเดียว (ตราประทับมีข้อความเสมอ)

## 9. Stack และข้อควรระวังเชิงเทคนิค

- Next.js (App Router) + React + TypeScript + **Tailwind CSS v3** + shadcn/ui (Radix) + lucide-react + sonner + react-hook-form/zod
- **ใช้ไวยากรณ์ Tailwind v3 เท่านั้น** เช่น `max-h-[var(--x)]`, `origin-[var(--x)]` — ไวยากรณ์ v4 อย่าง `max-h-(--x)` หรือ `origin-(--x)` ใน v3 จะไม่ถูกสร้าง CSS (ทำให้ dropdown ยาวไม่จำกัดความสูงและเลื่อนไม่ได้ — เคยเกิดขึ้นแล้วใน `select.tsx`/`popover.tsx`)
- `darkMode: 'class'`; token ทั้งหมดอยู่ใน `:root` และ `.dark` ใน `globals.css`; Tailwind อ้างผ่าน `hsl(var(--token))`
- ห้ามใส่ `richColors` ใน `<Toaster>` (จะทับสไตล์)
- ก่อนส่งงานตรวจ: ทุกหน้าใน light + dark, มือถือ 375px, รายการยาวใน select/combobox เลื่อนได้, ตราประทับ/เงา/เส้นประสม่ำเสมอ

## 10. Checklist ก่อนส่งทุกงาน

1. ไม่มีสีที่ hard-code นอกจาก token
2. ไม่มีมุมมนเกิน 4px
3. ไม่มี gradient / blur / เงาฟุ้ง
4. เส้นประ / เส้นคู่ / เงาแข็ง ใช้ตามตำแหน่งที่กำหนดเท่านั้น
5. สีแดงใช้เฉพาะจุดเน้น
6. ข้อความไทยทั้งหมด ตัวเลข/รหัสเป็น mono
7. ลูกเล่นไม่เกินที่ระบุ ("เบา ไม่เวอร์")

## ภาคผนวก: Prompt สำหรับโปรเจกต์อื่น

คัดลอกทั้งเอกสารนี้ไปเป็นข้อความแรกของโปรเจกต์ใหม่ แล้วเพิ่มบรรทัดเดียวถ้าเปลี่ยนแบรนด์:

> แบรนด์นี้ใช้สีหลัก `H S% L%` แทนแดง SNC (เปลี่ยนเฉพาะ `--primary`, `--ring`, `--sidebar-accent`) ส่วนอื่นคงเดิมตามเอกสาร
